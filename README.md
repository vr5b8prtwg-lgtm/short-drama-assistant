# 网剧自动生成工作流（Dify）

在本机 Dify（`http://127.0.0.1/`）中运行的**网剧（短剧）剧本自动生成**对话流应用：输入创意后先产出大纲与人物设定，确认后再批量生成分集剧本，并附质检报告。

## 核心特性

- **分阶段确认**：大纲与人物先给你确认，确认后才生成分集剧本，避免浪费。
- **试跑模式**：只生成第 1 集（约 500-800 字），全链路约 15 秒、成本约 ¥0.1，用于低成本验证。
- **高性价比模型组合**：创意用 `qwen-max`，批量分集与质检用 `qwen-turbo`，均为通义千问（tongyi）插件，无需额外安装插件。
- **单集重写**：确认后可对任意一集单独重写，不用整部重跑。
- **质检报告**：一致性、钩子强度、敏感词检查，输出需修订集数清单。
- **Git 版本管理**：工作流 DSL、提示词、文档全部纳入本仓库。

## 模型与成本

| 环节 | 模型 | 说明 |
|---|---|---|
| 大纲/人物/分集规划 | `qwen-max` | 创意与质量把关 |
| 批量分集/单集重写 | `qwen-turbo` | 高性价比、速度快 |
| 质检 | `qwen-turbo` | 需 131K 长上下文读取全剧本（qwen-max 仅 32K 会超限） |

- 试跑一次约 ¥0.1、约 15 秒（1 集）。
- 正式一部 12 集约 ¥2-8（以 Dify 控制台实际计费为准）。
- 若后续安装 DeepSeek 插件，可将批量节点切换为 `deepseek-chat`，成本更低。

## 快速开始

1. 打开 Dify 控制台（`http://127.0.0.1/`）。
2. 左侧「工作室 → 导入 DSL 文件」，选择 `dify/网剧自动生成.yml`。
3. 确认通义（tongyi）模型已配置 API Key（阿里云百炼）。
4. 打开应用，填写「创意描述 / 集数 / 每集字数 / 试跑模式」后发送。

详细步骤见 [docs/使用说明.md](docs/使用说明.md)。
