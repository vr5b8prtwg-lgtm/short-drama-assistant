# 使用说明

## 前置条件

- Dify 已在本机运行（`http://127.0.0.1/`）。
- 已安装「通义（tongyi）」模型插件并配置阿里云百炼 API Key（Dify 控制台 → 设置 → 模型供应商）。
- 使用通义模型需要百炼账号已开通对应模型权限。

## 导入工作流

1. 打开 Dify 控制台 → 右上角「工作室」。
2. 点击「导入 DSL 文件」，选择本仓库 `dify/网剧自动生成.yml`。
3. 导入成功后，在应用列表打开「网剧自动生成」。
4. 确认各 LLM 节点的模型选择为 `qwen-max` / `qwen-turbo`（导入后如显示为空，请手动选择）。

## 运行

打开应用后，在**输入表单**填写：

| 字段 | 说明 |
|---|---|
| 创意描述 | 必填。题材、主角、核心冲突、风格等 |
| 题材类型 | 可选。都市逆袭/古装权谋/悬疑推理/甜宠/战神归来/逆袭打脸/其他 |
| 目标集数 | 默认 12，范围 1-24 |
| 每集字数 | 默认 2500，范围 500-4000 |
| 试跑模式 | 否/是。选「是」只生成第 1 集（约 15 秒） |
| 爆款元素参考 | 可选。如：赘婿、逆袭、打脸、甜宠 |

**对话指令**：

- 首轮发送后，工作流返回大纲与人物设定。
- 回复「确认」→ 生成分集规划 + 全部分集剧本 + 质检报告。
- 回复「把男主改成冷酷总裁」等修改意见 → 按意见修订大纲，再次返回等你确认。
- 全集生成后，回复「重写第 3 集，节奏更快」→ 只重写第 3 集。
- 剧本包「一、大纲与人物设定」后自动附「人物定妆表」（全剧固定外观锚点），「四、文生视频提示词包」按集×场景给出出场角色/画面提示词/对白字幕，可直接提供给文生视频 AI（建议竖屏 9:16、每场景 4-6 秒），并可交给 `jimeng/` 管线自动生成 AI 漫剧。
- 其他消息会返回当前状态与可用指令。

## 导出与回导

- 修改工作流后，可在 Dify 控制台「导出 DSL」覆盖 `dify/网剧自动生成.yml`，保持仓库与线上一致。
- 本仓库的 YAML 可随时重新导入 Dify（无报错校验见 `scripts/validate_dsl.py`）。

## 常见问题

- **运行轨迹里剧本包内容在哪看？** 「组装剧本包」节点会输出完整剧本包，「输出剧本包」节点把它作为最终答案返回。中间不再有只写变量、无输出的节点。
- **更新工作流后旧对话报错？** 每次更新并发布后，请「新建对话」再运行；旧对话绑定的是更新前的工作流版本，可能与新版本不兼容。


- **提示模型未配置**：到「设置 → 模型供应商」为通义插件填入百炼 API Key。
- **导入后 LLM 节点模型为空**：在画布中为每个 LLM 节点选择模型（qwen-max / qwen-turbo）。
- **试跑超 15 秒**：多为模型排队延迟；正式生成不受影响。
- **分集规划解析失败**：代码节点会回退为单集兜底，不会中断流程。
